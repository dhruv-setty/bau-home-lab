# BAU home lab

Runbooks and scripts from my home lab, written the way I would run business-as-usual (BAU) IT support: Microsoft 365, Active Directory, Intune, ticketing and user-facing troubleshooting, plus an F5 BIG-IP vulnerability review.

All work here was done in a lab on local virtual machines and Docker containers, not in a production environment.
