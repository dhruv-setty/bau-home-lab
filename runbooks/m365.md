# Microsoft 365 user administration

## New starter
1. Confirm the request in the ticket: name, role, manager, start date, licence.
2. Create the user, set usage location, assign the licence.
3. Add to the role's groups and shared mailboxes.
4. Require MFA registration at first sign-in.
5. Send sign-in details to the manager by the agreed channel. Update the ticket.

## Leaver
1. Block sign-in and revoke sessions.
2. Convert the mailbox to shared or set forwarding, as the manager approves.
3. Remove licences and group memberships.
4. Record what was removed in the ticket and close it.

## Common requests
- Password reset: verify identity first, then reset and require change at next sign-in.
- Shared mailbox access: confirm approval from the mailbox owner, then grant Full Access or Send As.
- Licence change: check the licence is available before assigning.
