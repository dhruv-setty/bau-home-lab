# User-facing troubleshooting

Start with the user: what were they doing, what did they expect, what happened, and when did it last work.

| Problem | First checks |
| --- | --- |
| Cannot sign in | Account locked or disabled, password expired, MFA method changed |
| No email | Licence assigned, mailbox exists, Outlook profile, web access works |
| Printer not working | Printer online, correct queue, driver, clear stuck jobs |
| Slow computer | Disk space, startup apps, pending updates, restart |
| No network | Cable or Wi-Fi, IP address (`ipconfig`), DNS (`nslookup`), gateway reachable |

Explain the fix in plain words, and check the user can work before closing the ticket.
